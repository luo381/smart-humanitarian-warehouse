# Smart Humanitarian Warehouse: Warehouse Robot Navigation

CSCI218 group project (University of Wollongong in Dubai, Autumn 2026).

A simulated robot collects relief items from the warehouse racks and brings them to a
dispatch dock. It plans routes with A*, is controlled by a finite state machine, and
replans when an aisle becomes blocked.

## Where everything is

All code, data and results are in the [`my_robot`](my_robot) folder.
See [`my_robot/README.md`](my_robot/README.md) for the full description, method and results.

## Quick start

```
cd my_robot
python3 -m pip install -r requirements.txt
python3 validate.py
python3 test_project.py
python3 viewer.py
```
